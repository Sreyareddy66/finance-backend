# Finance Backend API

## Features
- User Register & Login (JWT)
- Role-based access (Admin/User)
- Create financial records
- MongoDB database

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose

## Run Project
npm install
node app.js

## API Endpoints
POST /api/auth/register
POST /api/auth/login
POST /api/records
